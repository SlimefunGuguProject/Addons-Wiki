# 箱子搬运车

## 用途

右键箱子可以将其装进搬运车
大箱子也可以被装走
被装走的箱子会保留全部内容物

<ImageGallery images={[{ src: "/images/fluffy-machines/dolly-full.png", alt: "一个装了箱子的搬运车" }]} />

再次对地面右键可将其放出
