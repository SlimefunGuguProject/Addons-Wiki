## 用途

与其他物品一起丢在地上可以为该物品赋予防火效果

:::warning

一次只能为一个物品赋予防火！

:::

<ImageGallery images={[{ src: "/images/fluffy-machines/fireproof.png", alt: "一个防火的干草捆" }]} />

当物品拥有防火属性后将不会被火焰或者岩浆销毁
