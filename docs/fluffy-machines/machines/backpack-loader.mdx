# 背包装装载机

可以直接往背包中添加物品

## 界面

<ImageGallery images={[{ src: "/images/fluffy-machines/backpack-loader.png", alt: "背包装载机的界面" }]} />

可以分为3个区域：

- **蓝色玻璃板框出区域**：放置需要装载的物品，支持货运输入。
- **左下角空槽**：放置需要装载的背包。**注意：在蓝色玻璃板框出区域放置的背包会直接转到该槽位**
- **右下角槽位**：在背包转满后会输出到该槽位

**电力消耗**: 32 J/s  
**可储存**: 48 J
