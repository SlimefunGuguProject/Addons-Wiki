# 背包卸载机

可以直接往背包中添加物品

## 界面

<ImageGallery images={[{ src: "/images/fluffy-machines/backpack-unloader.png", alt: "背包卸载机的界面" }]} />

可以分为2个区域：

- **左上角空槽**：放置需要卸载的背包。
- **下方两行空槽**：背包内容物输出槽位。

**电力消耗**: 32 J/s  
**可储存**: 48 J
