# 高级自动祛魔机

可以配合远古之书来取下物品上的指定附魔。

## 使用

打开高级自动祛魔机可以看到以下界面：

<ImageGallery images={[{ src: "/images/fluffy-machines/advanced-auto-disenchanter-meun.png", alt: "高级自动祛魔机" }]} />

**蓝色玻璃框出槽位**：放置需要去魔的物品。  
**黄色玻璃框出槽位**：放置[远古之书](./ancient-book)。  
**橙色玻璃框出槽位**：产物输出槽位。  
**中间的附魔书**：附魔选择按钮。
  
使用时，需要在**蓝色玻璃框出槽位**，**黄色玻璃框出槽位**填入对应物品。  
然后点击附魔选择按钮选择要取下的附魔。

<ImageGallery images={[{ src: "/images/fluffy-machines/advanced-auto-disenchanter-choice.png", alt: "选择要取下的附魔" }]} />

随后机器会自动运行，30s后在输出槽位输出附魔书与被去魔物品。

## 信息

**电力消耗**: 2048 J/s  
**可储存**: 4096 J
