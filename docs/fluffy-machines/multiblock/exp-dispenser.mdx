# 经验收集器

<ImageGallery images={[{ src: "/images/fluffy-machines/exp-dispenser.png", alt: "经验收集器" }]} />

## 建造

在地上放置一个发射器，然后在上面放置一个砂轮。

<ImageGallery images={[{ src: "/images/fluffy-machines/exp-dispenser-full.png", alt: "完整的经验收集器" }]} />

## 使用

在发射器面朝的位置放置一个蓬松箱子。  
蓬松箱子内装附魔之瓶(或者直接装填在发射器中)。  
然后点击砂轮即可一次性获取蓬松箱子或者发射器中附魔之瓶的全部经验。
