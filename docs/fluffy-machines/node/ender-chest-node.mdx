# 末影货运节点

从你的末影箱中提取物品
可以用于跨维度物品传输

<ImageGallery images={[{ src: "/images/fluffy-machines/ender-chest-node.png", alt: "输入和输出的末影节点" }]} />

## 用法

将节点贴着末影箱放置，末影节点放置后将自动绑定你的uuid

:::warning

末影节点只能调动你的末影箱空间，不能调动其他玩家的！

:::

  images={[{ src: "/images/fluffy-machines/ender-chest-node-working.png", alt: "一个正确放置的输入节点" }]}
